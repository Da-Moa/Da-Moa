# 금융기관 로고 출처

은행 선택창은 이 디렉터리의 이미지만 사용하며 외부 CDN에 접속하지 않습니다.

- 기본 SVG: [korea_bank_icons](https://github.com/flxh4894/korea_bank_icons/tree/80c40ce55baff328c97de6a2d65f84cef82b7f6f/assets/icons), commit `80c40ce55baff328c97de6a2d65f84cef82b7f6f`. MIT 라이선스 원문은 `LICENSE.korea-bank-icons.txt`에 보관합니다. 금융기관 이름·선택 목록은 앱의 `src/lib/bank-account.ts`를 따릅니다.
- `012.svg`: 지역농축협이 사용하는 NH 심볼로 `011.svg`와 동일합니다.
- `030.svg`: 수협중앙회가 사용하는 수협 심볼로 `007.svg`와 동일합니다.
- `031.svg`, `262.svg`: [Toss의 현재 iM 심볼](https://static.toss.im/icons/svg/icon-bank-dgb.svg). `262`의 브랜드는 [iM증권 공식 사이트](https://www.imfnsec.com/)의 로고와 대조했습니다. 기본 패키지의 이전 DGB·하이투자증권 로고를 대체합니다.
- `265.svg`: [Toss의 LS증권 로고](https://static.toss.im/icons/svg/icon-bank-ls.svg). [LS증권 공식 CI](https://ir.ls-sec.co.kr/companykor/pr/ci.jsp)와 대조했습니다. 기본 패키지의 이베스트투자증권 로고를 대체합니다.
- `227.png`: [다올투자증권 공식 사이트의 로고](https://daolsecurities.com/image/logo_header_b.png?ver=0.0.3).

로고의 색상과 비율은 원본을 유지합니다. 각 금융기관 로고의 상표권은 해당 금융기관에 있습니다.
