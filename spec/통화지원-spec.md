# 회차 통화 지원

선정일: 2026-10-01. 사용자 결정: **공개 통계와 주요 여행국 보완으로 진행**.

## 선정 기준과 한계

한국인의 해외 방문 목적지를 기준으로 한다. 한국으로 입국하는 외국인 순위나 전 세계 관광객 순위를 대신 사용하지 않는다. 한국관광공사의 [2025년 12월 기준 국민 해외관광객 주요 목적지별 통계 안내](https://touraz.kr/statistics?bbsSeq=310224_1127&boardMode=V)는 출국카드 폐지와 국가별 통계 확보의 한계를 명시한다. 따라서 아래는 공식 방문자 수 TOP 50 순위가 아니라, 주요 목적지 통계를 참고하고 여행국으로 보완한 **50개 목적지의 지원 범위**다. 첨부 통계의 전체 수치와 엄격한 1~50위는 검증하지 않았으며 순위·방문자 수를 제시하지 않는다. 홍콩·마카오·대만을 별도 여행 목적지로 포함하고 괌·사이판은 미국의 USD 지원으로 포함한다.

공통 통화는 한 번만 추가한다. 국내 KRW를 유지하여 총 **41종(기존 3종 + 신규 38종)**을 제공한다. 자국 통화와 여행 중 널리 쓰이는 외국 통화를 함께 허용하되, 한 회차에는 한 통화만 저장한다.

## 기존 정책의 확장

- 통화 목록·한글 이름·자릿수·검색용 국가는 `src/lib/money.ts`의 `CURRENCIES`를 사용한다. UI·API 검증·OpenAPI는 같은 목록을 사용하고 DB 제약은 `015-expanded-round-currencies.sql`로 확장한다.
- 입력·수정·개별 부담금·한도·나머지·정산은 정확한 문자열과 BigInt 최소 단위를 유지한다. 지출 100,000,000 / 회차 1,000,000,000 주 단위 한도는 모든 통화에 동일하다.
- 기존 KRW·JPY·USD 표시와 저장값을 유지한다. 신규 통화는 `1,234.56 EUR`, `1,234 VND`처럼 코드로 구분한다. 동일한 달러·페소 기호가 다른 통화를 혼동시키지 않게 한다.
- 생성 후 통화 변경, 환전, 서로 다른 회차의 통화 합산은 제공하지 않는다. 기존 회차와 정산 금액은 변환하지 않는다.
- 수취 계좌는 기존대로 KRW에서 실제 지급할 수취인만 공개하며 모든 외화는 상대방·금액만 안내한다.
- 통화 선택 목록은 `대한민국 원` / `미국 달러` / `일본 엔` 형식의 나라·통화 이름과 SVG 국기 이미지로 표시하고, 코드·한글 이름·나라로 검색한다. 국기는 기존과 같은 MIT 라이선스 flag-icons v7.3.2를 사용한다. 기존 네이티브 dialog·select·입력 컨트롤과 키보드 포커스를 유지한다.

이 문서의 확장은 `정산기능-spec.md`의 세 통화 전용 설명을 대체하며, 상태·권한·확인·멱등성 규칙은 유지한다.
