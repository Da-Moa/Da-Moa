## 프로젝트 소개

**다모아**는 로그인한 참여자들이 모임을 만들고, **함께 쓴 돈을 회차별로 정리하는 앱**입니다. 지출마다 **결제자와 부담자**를 선택하면 개인별 부담액과 정산 금액을 계산하고, **누구에게 얼마를 보내야 하는지** 안내합니다.

## 주요 기능

| 도메인 | 주요 기능 |
| --- | --- |
| 👥 모임 | **최대 10명**이 참여하는 모임을 만들고 **초대 링크**로 사용자를 초대합니다. |
| 🗓️ 회차 | 모은 사용자와 함께 **정산할 기록**을 만듭니다. |
| 🧾 지출 | 회차에서 **지출을 기록**하고, **영수증을 업로드**하면서 실시간으로 **송금 관계**를 확인합니다. |
| 💸 안내 | 내가 송금해야 하는 **금액과 대상**을 확인하고, 송금할 수 있도록 **계좌번호**를 확인합니다. |
