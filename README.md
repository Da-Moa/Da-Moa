## 프로젝트 소개

**다모아**는 카카오로 로그인한 참여자들이 모임을 만들고, 함께 쓴 돈을 회차별로 정리하는 앱입니다. 지출마다 결제자와 부담자를 선택하면 개인별 부담액과 정산 금액을 계산하고, 누구에게 얼마를 보내야 하는지 안내합니다.

국내 모임부터 해외여행까지 **41종 통화**를 지원합니다. 한 회차에 최대 **5개 통화**를 기록하고, 각 통화의 지출과 정산 금액을 따로 확인할 수 있습니다.

## 주요 기능

| 기능 | 소개 |
| --- | --- |
| 🔑 카카오 로그인 | 카카오 계정으로 로그인하고 은행·계좌번호·예금주를 직접 등록합니다. |
| 👥 모임과 초대 | 최대 10명이 참여하는 모임을 만들고 초대 링크로 참여자를 모읍니다. |
| 🗓️ 회차별 기록 | 모임 안에서 회차를 만들고 참여자를 선택해 지출을 기록합니다. 종료된 회차는 정산 기록에서 다시 확인합니다. |
| 🧾 지출과 영수증 | 지출 날짜·금액·통화·결제자·부담자를 입력하고 영수증 이미지를 첨부합니다. |
| ⚖️ 부담금 분배 | 전체 또는 선택한 참여자끼리 균등하게 나누거나, 개별 부담금을 직접 지정합니다. 균등 분배의 나머지는 한 번의 추첨으로 배분합니다. |
| 🌍 통화별 정산 | 서로 다른 통화를 합산하거나 환전하지 않고, 통화별 보낼 금액과 받을 금액을 계산합니다. |
| 💸 개인 정산 안내 | 본인의 송금 상대와 금액을 확인하고 안내 링크를 복사합니다. 원화 송금에는 실제 수취인의 최신 계좌를 표시합니다. |
| ✅ 수취 확인과 종료 | 수취인이 송금자·통화별 입금을 직접 확인하고, 회차 생성자가 정산을 종료합니다. |
| 🔄 실시간 갱신 | 지출·정산 변경을 WebSocket 알림으로 반영하고 기기의 라이트·다크 모드를 따릅니다. |

## 이용 흐름

**카카오 로그인 → 모임 생성·초대 → 회차 생성 → 지출 기록 → 정산 확정·전송 → 수취 확인 → 정산 종료**

회차 생성자가 정산을 확정하며, 전송 전에는 다시 기록 단계로 열 수 있습니다. 전송하면 원본 기록이 잠기고, 필요한 경우 나머지를 추첨한 뒤 개인 정산 안내를 확인합니다. 종료된 회차는 읽기 전용으로 보존됩니다.

송금은 안내를 보고 직접 진행하며 수취인도 입금을 직접 확인합니다. 계좌는 수동으로 등록하고, 확인 이력이 없는 계좌에는 `확인되지 않은 계좌입니다.`를 표시합니다.
